A single self-invented comedy one-liner about a serial plant-killer who buys fake plants — then keeps watering them anyway, just to keep the lie alive. Running `main.py` writes that one line to `/output/entry.txt` for make.fun's "One-Liner Marathon" bounty.

## Run it

```sh
python3 main.py
```
